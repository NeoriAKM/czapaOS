## Features

This OS **has no features**, which separates it from other loaders or shells without an OS

## Building

**Requirements**:
- `NASM`
- `QEMU` (for running)

This script **compiling**, and **building** an img file. Then it runs `QEMU`

```bash
./build.sh
```
